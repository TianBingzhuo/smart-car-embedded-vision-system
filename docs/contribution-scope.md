# Project Ownership And Contributions

The 19th Vision Group vehicle was a five-person team project. The complete system and competition result depend on the interaction of firmware, vision, mechanics, electronics, and field debugging.

| Member | Main contribution |
|---|---|
| 戴哲维 | Main program and RT1064 vehicle-control firmware. |
| 葛洪飞 | Main program and RT1064 vehicle-control firmware. |
| 黄得时 | Mechanical structure and mechanism work. |
| 么林坤 | Vision system, including OpenART-related recognition work. |
| 田秉卓 | PCB design, soldering, board iteration, hardware bring-up support, and repository maintenance. |

## Material Map

- `firmware/rt1064/` corresponds primarily to the main-program work by 戴哲维 and 葛洪飞.
- `firmware/openart/` corresponds primarily to the vision work by 么林坤.
- `hardware/pcb/` records PCB work by 田秉卓.
- Mechanical work by 黄得时 is part of the complete vehicle even though the current repository is centered on firmware and electronics.

# 项目署名与贡献

第十九届视觉组整车由五人团队共同完成。固件、视觉、机械、电路和现场调试缺一不可。

| 成员 | 主要贡献 |
|---|---|
| 戴哲维 | 主程序与 RT1064 整车控制固件。 |
| 葛洪飞 | 主程序与 RT1064 整车控制固件。 |
| 黄得时 | 机械结构与机构相关工作。 |
| 么林坤 | 视觉系统，包括 OpenART 识别相关工作。 |
| 田秉卓 | PCB 设计、焊接、板级迭代、硬件联调支持与仓库维护。 |

## 材料对应关系

- `firmware/rt1064/` 主要对应戴哲维、葛洪飞的主程序工作。
- `firmware/openart/` 主要对应么林坤的视觉工作。
- `hardware/pcb/` 记录田秉卓的 PCB 工作。
- 黄得时的机械工作属于完整整车成果，当前仓库重点在固件和电路，因此未完整呈现机械部分。
